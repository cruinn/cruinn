Foco: Inteligência Artística, Estrutura Poética e Análise de Linguagem Natural

Descrição do Projeto:
Eu tive uma ideia: eu quero criar um projeto como meu primeiro projeto. Estou estudando Python e agora estou começando a me interessar nisso. Meu objetivo é criar um projeto e postar no GitHub como meu primeiro projeto principal, que pode me garantir vagas em empresas grandes e também servir como um objetivo principal pra focar durante meu curso de Python.

Minha ideia seria criar um sistema como se fosse um cérebro que pensa e envia informações para os dados. Esses dados serão letras de músicas, que o cérebro vai precisar aprender com elas e aprender com as letras que o usuário manda, mas sem ficar rimando que nem IA, e sim entender padrões utilizados por humanos — uma escrita humanizada —, com o objetivo de ajudar as pessoas a escreverem músicas, poemas, textos.

Objetivo:
Aprender a entender a linguagem humana seguindo as informações recebidas pelo "User".

Exemplo de Fluxo:
User envia -> cérebro recebe, analisa.
[O quadrado do "topo" funciona como um segundo cérebro].

Arquitetura Visual:
No desenho, é representado pela cor vermelha; já os dados são representados por quadrados brancos. Eu quero criar um projeto que seja um cérebro que vai servir pra pensar todos os dados brancos. Como eu pensei em ligá-los uns nos outros, pensei em usar nodes (talvez o n8n ou outro middleware que eu desconheça, ou até criarmos um do zero usando Python).
